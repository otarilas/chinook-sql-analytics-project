# Chinook SQL Analytics Project

Analyzing the Chinook SQLite database from beginner to advanced queries to answer business questions about sales, customers, genres, and artists.

## Tools
- SQLite
- DBeaver
- SQL
- Visual Studio Code
- GitHub

## Project Goal
The goal of this project is to practice SQL skills and analyze a digital music store database.

## Skills Practiced
- SELECT
- WHERE
- ORDER BY
- JOIN
- GROUP BY
- Aggregations
- Subqueries
- Business analysis

## Project Structure
- `sql/`: SQL query files
